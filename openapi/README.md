# Модульная OpenAPI-спецификация

`index.json` — точка входа для lint и сборки модульной спецификации. Редактируемые маршруты разложены по смысловым группам в `modules/`, а общие DTO находятся в `components/schemas.json`.

`API_CONTRACT.json` в корне репозитория сохраняется как единый собранный контракт для потребителей, которым нужен один файл. Источник изменений — файлы в `openapi/`; после их изменения обновляйте корневой контракт сборкой:

```powershell
npx @redocly/cli lint openapi/index.json
npx @redocly/cli bundle openapi/index.json --output API_CONTRACT.json
```

## Модули

- `identity-admin.json` — аутентификация, администрирование пользователей и ролей, безопасность, SaaS-тенанты и аудит.
- `asset-management.json` — классы активов, активы, история активов и справочники.
- `service-desk-core.json` — заявки, назначение исполнителей, SLA, календари и настройки Service Desk.
- `forms-portal.json` — шаблоны форм, сообщения и уведомления.
- `reporting.json` — отчеты и управление доступом к ним.

Маршрут относится к модулю по его OpenAPI-тегам. Общие схемы централизованы, чтобы межмодульные ссылки оставались единообразными; каждый модуль публикует ссылки только на используемые им схемы.
