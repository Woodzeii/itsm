# ITSM Test Runner

Консольное приложение для запуска тестов из корня репозитория:

```powershell
dotnet run --project scripts\TestRunner\TestRunner.csproj
```

В меню доступны тесты проекта `backend\itsm.Tests` и JavaScript-тесты верхнего уровня папки `scripts`. Для нагрузочных скриптов требуется установленный [k6](https://grafana.com/docs/k6/latest/set-up/install-k6/); для E2E — Node.js, npm и Playwright.

Для скрипта, в имени которого есть `load` (нагрузочный тест), приложение запрашивает адрес API, число виртуальных пользователей, длительность, порог ответа, необязательный ID справочника и JWT-токен. Если токен не введён, скрипт использует `LOAD_TEST_JWT_TOKEN` из `backend\.env`. Перед запуском теста настройте API и базу данных.

## Smoke E2E авторизации

Тест проверяет вход, TOTP, JWT, выбор роли «Администратор» и переход на `/admin/settings` (текущий маршрут администратора в приложении). Страницы и переходы проверяются на загрузку не дольше 2 секунд; ответы HTTP 400, 401 и 403 считаются ошибкой теста.

Установите зависимости и браузер из корня репозитория:

```powershell
npm --prefix scripts install
npm --prefix scripts run install:playwright
```

Перед запуском должны быть доступны фронтенд и API. Тестовому пользователю нужны роли `admin` и как минимум одна дополнительная роль, включённая 2FA и секрет, совпадающий с `E2E_TOTP_SECRET` (Base32). Seed-пользователь `admin` имеет только одну роль и для этого сценария не подходит (позже это убрать). 

Задайте переменные окружения и запустите тест:

```powershell
$env:E2E_BASE_URL = "http://localhost:4200"
$env:E2E_ADMIN_USERNAME = "..."
$env:E2E_ADMIN_PASSWORD = "..."
$env:E2E_TOTP_SECRET = "..."
npm --prefix scripts run test:auth-smoke
```

`E2E_BASE_URL` необязателен и по умолчанию равен `http://localhost:4200`. При выборе `auth-smoke-e2e.js` в TestRunner введите логин, пароль и TOTP-секрет; пароль и секрет вводятся без отображения. Если соответствующие переменные окружения уже заданы, Enter оставит их значения по умолчанию. TestRunner передаёт значения дочернему npm-процессу и не сохраняет их в исходниках.
